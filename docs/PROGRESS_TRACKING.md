
# Pemantauan Progres Proyek CodeTutor

## 1. Tujuan

Dokumen ini digunakan oleh Project Manager untuk mencatat,
memantau, dan mengevaluasi perkembangan pekerjaan seluruh
anggota tim selama pengembangan CodeTutor.

Pemantauan dilakukan berdasarkan timeline proyek,
pembagian tanggung jawab, hasil pekerjaan, dan bukti
kontribusi yang tersedia di repositori GitHub.

## 2. Periode Pemantauan

Periode proyek: 2 September–15 Desember 2026

Model pengembangan: Waterfall

Project Manager: Rahmadi

## 3. Status Pekerjaan

Status yang digunakan dalam pemantauan:

- Belum Dimulai
- Sedang Dikerjakan
- Dalam Peninjauan
- Selesai
- Tertunda

Setiap status harus mencerminkan kondisi pekerjaan
yang sebenarnya.
