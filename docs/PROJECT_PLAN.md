
# Rencana Proyek CodeTutor

1. Gambaran Umum

CodeTutor merupakan platform pembelajaran pemrograman
berbasis web yang dirancang untuk membantu pengguna
mempelajari pemrograman melalui materi, Code Lab,
evaluasi, chatbot AI, dan pemantauan progres belajar.

2. Tujuan Proyek

- Menyediakan materi pembelajaran pemrograman.
- Mendukung latihan kode melalui Code Lab.
- Menyediakan evaluasi pemahaman pengguna.
- Mengintegrasikan chatbot AI sebagai pendamping belajar.
- Memantau progres belajar pengguna.

3. Ruang Lingkup

Pengembangan mencakup:
- Manajemen akun dan hak akses pengguna.
- Pengelolaan materi pembelajaran.
- Fitur Code Lab dan evaluasi.
- Integrasi chatbot AI.
- Pemantauan progres belajar.
- Pengelolaan data melalui basis data.

4. Peran Project Manager

Project Manager bertanggung jawab untuk:
- Menetapkan tujuan dan ruang lingkup proyek.
- Mengoordinasikan pembagian tugas tim.
- Memantau perkembangan pekerjaan.
- Mengidentifikasi kendala dan risiko proyek.
- Memastikan hasil pekerjaan sesuai kebutuhan.
- Mengoordinasikan evaluasi dan penyelesaian proyek.

5. Teknologi yang Digunakan

- PHP dan Laravel
- MySQL
- HTML, CSS, dan JavaScript
- Tailwind CSS
- Gemini API
- Git dan GitHub

6. Pemantauan Proyek

Perkembangan proyek dipantau melalui:
- Status penyelesaian tugas.
- Riwayat perubahan kode di GitHub.
- Pengujian fitur.
- Evaluasi hasil pengembangan.
- Dokumentasi kendala dan tindak lanjut.

7. Catatan

Rencana ini menjadi dokumen awal pengelolaan proyek.
Rincian jadwal, penanggung jawab tugas, dan status
pekerjaan perlu disesuaikan dengan kondisi proyek
yang sebenarnya.
