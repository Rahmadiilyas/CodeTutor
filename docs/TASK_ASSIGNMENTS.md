Pembagian Tugas Tim CodeTutor

Dokumen ini menjelaskan pembagian peran, tanggung jawab,
dan koordinasi anggota tim dalam pengembangan CodeTutor.

1. Tujuan

Dokumen pembagian tugas ini dibuat sebagai pedoman kerja
tim agar setiap anggota memahami tanggung jawabnya masing-masing.

Selain itu, dokumen ini menjadi acuan bagi Project Manager
dalam mengoordinasikan dan memantau perkembangan proyek.

2. Struktur Tim dan Pembagian Tugas

2.1 Rahmadi
**Peran:** Project Manager

**Tanggung Jawab:**
- Menyusun perencanaan dan prioritas proyek.
- Mengoordinasikan seluruh anggota tim.
- Memantau perkembangan pekerjaan setiap anggota.
- Mengidentifikasi kendala dan risiko proyek.
- Mengelola dokumentasi serta laporan perkembangan proyek.
- Mengoordinasikan evaluasi hasil pekerjaan tim.

2.2 Ariqah
**Peran:** System Analyst

**Tanggung Jawab:**
- Menganalisis kebutuhan sistem.
- Mengidentifikasi kebutuhan fungsional dan nonfungsional.
- Menyusun dokumentasi analisis kebutuhan.
- Menjelaskan kebutuhan sistem kepada tim pengembang.

2.3 Fardina
**Peran:** System Designer

**Tanggung Jawab:**
- Merancang arsitektur sistem.
- Menyusun alur proses sistem.
- Mendokumentasikan rancangan sistem.
- Memastikan rancangan sesuai dengan kebutuhan aplikasi.

2.4 Rifqah
**Peran:** UI/UX Designer

**Tanggung Jawab:**
- Merancang tampilan antarmuka aplikasi.
- Menyusun alur interaksi pengguna.
- Membuat desain halaman dan komponen antarmuka.
- Memastikan desain mudah digunakan dan konsisten.

2.5 Siti Mariati
**Peran:** Database Designer

**Tanggung Jawab:**
- Merancang struktur basis data.
- Menentukan tabel dan atribut yang diperlukan.
- Menyusun relasi antartabel.
- Mendokumentasikan rancangan basis data.

2.6 Rayhan
**Peran:** Frontend/Backend Developer

**Tanggung Jawab:**
- Mengembangkan antarmuka aplikasi.
- Mengimplementasikan logika dan fungsi sistem.
- Menghubungkan aplikasi dengan basis data.
- Mengintegrasikan fitur sesuai rancangan sistem.

2.7 Silfi Kurnia
**Peran:** Tester / Quality Assurance

**Tanggung Jawab:**
- Menyusun skenario pengujian.
- Melakukan pengujian fitur aplikasi.
- Mencatat kesalahan atau bug yang ditemukan.
- Mendokumentasikan hasil pengujian.
- Memastikan fitur berjalan sesuai kebutuhan.


3. Tanggung Jawab Project Manager

Sebagai koordinator tim, Project Manager memiliki tanggung
jawab utama dalam memastikan proses pengembangan berjalan
terarah dan sesuai dengan rencana.

Fokus koordinasi meliputi:

1. **Perencanaan:** Menetapkan target dan prioritas pekerjaan.
2. **Koordinasi:** Memastikan komunikasi antaranggota berjalan baik.
3. **Pemantauan:** Memeriksa perkembangan setiap tugas.
4. **Pengendalian:** Mengidentifikasi kendala dan menentukan tindak lanjut.
5. **Evaluasi:** Meninjau hasil pekerjaan dan memastikan kesesuaiannya.

## 4. Status Pekerjaan

Untuk memudahkan pemantauan, tim menggunakan empat status pekerjaan:

- **Belum Dimulai** — Tugas belum dikerjakan.
- **Sedang Dikerjakan** — Tugas sedang dalam proses pengerjaan.
- **Dalam Peninjauan** — Hasil pekerjaan sedang diperiksa.
- **Selesai** — Tugas telah diselesaikan.

Setiap anggota diharapkan memperbarui perkembangan
pekerjaannya sesuai dengan kondisi yang sebenarnya.

5. Ketentuan Koordinasi

- Setiap anggota bertanggung jawab terhadap tugas sesuai perannya.
- Perubahan pekerjaan perlu dikomunikasikan kepada Project Manager.
- Kendala selama pengembangan harus disampaikan kepada tim.
- Hasil pekerjaan didokumentasikan melalui repositori GitHub.
- Evaluasi dilakukan untuk memastikan perkembangan proyek tetap terarah.

6. Penutup

Dokumen ini menjadi pedoman awal pembagian tanggung jawab
dalam pengembangan CodeTutor. Pembagian tugas dapat
disesuaikan berdasarkan kebutuhan dan kesepakatan tim
selama proses pengembangan berlangsung.
