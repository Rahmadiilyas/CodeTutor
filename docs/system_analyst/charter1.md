IDENTITAS PROYEK
Nama proyek	CodeTutor   : Platform Pembelajaran Pemrograman Berbasis Web dengan Integrasi Chatbot AI
Jenis sistem            : Aplikasi web
Bidang                  : Pendidikan, pembelajaran pemrograman berbantuan AI
Mata kuliah             : Proyek Perangkat Lunak (Informatika, B2023)
Dosen pengampu          : Mawardi Kudin, S.Pd., M.Kom dan Wawan Firgiawan, S.T., M.Kom
Model pengembangan      : Waterfall
Periode                 : 2 September – 15 Desember 2026 (15 minggu)

AKTOR dan HAK AKSESNYA 
1. Admin        : Mengelola akun Instruktur (tambah, ubah, nonaktifkan) dan menonaktifkan akun Pelajar; melihat aktivitas, seluruh konten, evaluasi, dan progres. mengelola referensi chatbot, melihat catatan perubahan konten dan penerbitan sertifikat.
2. Instruktur   : Mengelola bahasa, modul, materi, media, latihan Code Lab, soal dan penilaian pre-test/post-test, referensi chatbot, melihat hasil dan progres pelajarnya, menerbitkan sertifikat.
3. Pelajar      : Mengakses materi dan media, memakai Code Lab, mengerjakan evaluasi, bertanya ke chatbot, melihat hasil dan progres milik sendiri, mengunduh sertifikat.


Tujuan Utama CodeTutor
1. Menggabungkan materi, media, Code Lab, evaluasi, chatbot AI, progres, dan sertifikat dalam satu platform.
2. Membagi hak akses untuk Admin, Instruktur, dan Pelajar.
3. Memudahkan Instruktur menyusun konten dengan urutan bahasa → modul → materi.
4. Menyediakan pre-test dan post-test yang tersambung dengan riwayat belajar.
5. Menyediakan Code Lab supaya pelajar bisa menulis dan menjalankan kode langsung di website dengan aman.
6. Menyediakan chatbot Gemini yang menjawab berdasarkan referensi dari Admin/Instruktur.
7. Mencatat aktivitas penting supaya perubahan konten, evaluasi, dan sertifikat bisa dilacak.
8. Mengurangi pekerjaan administratif yang berulang dan membantu pelajar belajar mandiri.
