#METODE IDENTIFIKASI PENGGUNA
Kebutuhan sistem pada proyek ini diidentifikasi melalui studi dokumen dan brainstorming atau diskusi tim. Kedua metode itu digunakan untuk memahami permasalahan, tujuan proyek, karakteristik pengguna, fitur sistem, hak akses, serta kebutuhan fungsional dan nonfungsionalnya.

#KEBUTUHAN PENGGUNA
1. Admin
- Login dan melihat dashboard pengawasan
- Menambah, mengubah, dan menonaktifkan akun Instruktur
- Menonaktifkan akun Pelajar
- Melihat aktivitas Instruktur dan Pelajar
- Melihat bahasa, modul, materi, media, pre-test, dan post-test
- Memantau nilai evaluasi dan progres semua Pelajar
- Mengelola referensi jawaban chatbot
- Melihat riwayat perubahan konten dan penerbitan sertifikat

2. Instruktur
- Login dan melihat dashboard pembelajaran
- Menambah, mengubah, dan menghapus bahasa pemrograman
- Mengelola modul dan urutannya
- Mengelola materi dan urutannya
- Mengunggah media, menambah link YouTube, dan menghubungkan media ke materi
- Mengelola contoh kode atau latihan Code Lab
- Mengelola soal pre-test
- Mengelola soal evaluasi di tengah pembelajaran (di SRS disebut kuis, lihat ISS-01)
- Mengelola soal post-test
- Mengatur ketentuan penilaian
- Mengelola referensi jawaban chatbot
- Melihat nilai evaluasi dan progres Pelajar
- Menentukan kelayakan dan menerbitkan sertifikat

3. Pelajar
- Login dan melihat dashboard perkembangan belajar
- Melihat bahasa, modul, materi, dan membuka media
- Membuka Code Lab, memilih bahasa, menulis, mengubah, menjalankan kode, dan melihat hasilnya
- Mengerjakan pre-test dan post-test, lalu melihat nilainya
- Memakai chatbot AI
- Melihat progres dan pencapaian belajar
- Melihat dan mengunduh sertifikat
